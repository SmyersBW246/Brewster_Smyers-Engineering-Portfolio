# Transcript course research, 2026-11-11

Every course number on Brewster's unofficial Bucknell transcript (dated 10-13), checked against Bucknell's own catalog. This repository is public, so this file records course numbers, titles and terms only. Grades, GPA and identifiers stay out of the repository.

**Method.** Each code was pulled from the catalog's course lookup (`coursecatalog.bucknell.edu/ribbit/?page=getcourse.rjs&code=...`) for the current 2026-2027 catalog and the 2025-2026 and 2024-2025 archives, and the descriptions were compared across years. Program pages (Mathematics, Physics & Astronomy, Mechanical Engineering) were read for the minor rules and the missing codes.

## Mathematics minor (MATH 303)

The 2026-2027 Mathematics page: the minor needs four MATH/STAT credits numbered MATH 211/STAT 216 or above, all taken at Bucknell; at least one from MATH 211, 212, 241, 245 or 280; at least one at the 300 or 400 level. MATH 211, MATH 212, MATH 227 and MATH 303 satisfy those written rules (MATH 303 is the 300-level course). The transcript's program section lists only the B.S. in Mechanical Engineering, so a declared minor is not shown on it.

## Where sources disagree or are thin

- **PHYS 211P.** No catalog entry in 2024-25, 2025-26 or 2026-27, and catalog search returns nothing. A search-engine copy of Bucknell's Banner course record describes it as the required problem session for PHYS 211 (1 credit, fall, corequisites PHYS 211 and PHYS 211L). The Banner page itself is not reachable from outside Bucknell. The PHYS 211 Fall 2026 course calendar on eg.bucknell.edu shows problem sessions between lectures. The transcript shows only PHYS 211P, not PHYS 211.
- **MATH 227.** Present in the 2024-25 and 2025-26 catalogs; gone in 2026-27, where STAT 227 has the same title and description and excludes students with MATH 227 credit.
- **MECH 205.** Taken Spring 2026 but absent from the 2024-25 and 2025-26 catalogs; first appears in 2026-27.
- **FOUN 098 and RELI 100.** The catalog gives only the generic course. The section titles come from the transcript. Web search found Fall 2023 listings and orientation schedules naming FOUN 098 "Deviance & Deviant Identities" with the same instructor, but no syllabus. Nothing found for the RELI 100 section.
- **Small catalog wording changes** between 2025-26 and 2026-27 (prerequisites now accept CSCI 203; some courses now "majors only"; topics-course labels added). None changes course scope.
