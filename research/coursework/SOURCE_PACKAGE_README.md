# Brewster Smyers: Bucknell coursework research package

Prepared October 30, 2026 for the separate Digication implementation agent. This package contains 25 researched course records: 22 full public-facing drafts with expanded technical references and 3 deliberately limited records. No website was edited, built or published by the research team.

## Start here

Give the extracted folder to the website agent and have it read [DIGICATION_AGENT_HANDOFF.md](DIGICATION_AGENT_HANDOFF.md) first. Its opening prompt is self-contained. Then use [COURSE_INVENTORY.csv](COURSE_INVENTORY.csv) and [BUILD_ORDER.md](BUILD_ORDER.md).

## What is complete

The course inventory is based on 24 visually reviewed course codes in the supplied degree-audit crops plus MECH 438, confirmed separately by the student's project description. Official identity and course scope use public Bucknell catalog records. The audit header identifies Fall 2025-2026 as the catalog term; this is not the term in which every listed class was attended.

Each course folder contains a portfolio draft, a detailed technical reference, metadata, source mappings and evidence notes. Quantitative references include original representative problems and worked calculations. Equations, assumptions, units and source locators stay together. Original technical diagrams are labeled illustrative; the AUV and biplane images are actual supplied work. No AI-generated project photographs or renders were created for this package.

## How to interpret completion

**Complete draft** means the research/content document is complete. It does not mean the student completed the class, verified every personal statement, or that the page has been implemented. A course can have complete technical content and still require a personal-status check.

**Limited record** applies to ENGR 099, FOUN 098 and RELI 100. ENGR 099 has sparse documented seminar scope; the latter two need the actual section/topic. Their finished evidence records are intentionally shorter than the 500-800 word full-draft target. They are not counted as full course pages, and no fictional engineering equations were added.

MECH 205 has a full professional-practice draft, but its description was verified only in the 2026-2027 catalog. Its historical applicability and the student's course status remain unresolved.

## Evidence labels

- **Bucknell-verified:** course identity and documented scope from official records.
- **Standard technical/scholarly content:** independently researched principles and original representative examples; not proof of a particular lesson or assignment.
- **Personal evidence:** reviewed student materials or direct user-confirmed activities, with their limits.
- **Student verification required:** attendance/completion, section-specific content, unseen assignments, personal reflection, or an unproven resolution. Keep these claims out of public biography until resolved.

## Files and reuse

`01_COURSE_PAGES` contains the authored page text and full references. `02_SHARED_ASSETS/equations` provides machine-readable and standalone LaTeX transfer files. `03_RESEARCH` holds the source register, course-verification matrix, project mapping and reviewed source records. `04_STUDENT_VERIFICATION` collects one consolidated question list and a course-by-course artifact-selection matrix. `05_IMPLEMENTATION` provides layout guidance, an asset catalog and acceptance checks.

The private source material in `03_RESEARCH/personal_evidence` is for review only. Do not automatically publish degree-audit crops, full reports, resume contact details, proposals, or the full package. Select only intended public content and caption it precisely.

## Important evidence limits

The audit crops do not establish completed/current/planned/transfer status. Original Spitfire code/report, standalone final biplane report, newer AUV team results and manufacturing laboratory images were not available for direct review. The latest supplied biplane code was statically inspected; MATLAB was not executed. Code safeguards and calibration are not proof of flight validation. Source URLs were retrieved or supported by indexed primary-source content; future availability is not guaranteed. Some SOLIDWORKS live help pages exposed a navigation shell while indexed vendor text supplied the cited passage.

Begin implementation with the strongest documented manufacturing, aircraft and fluids content. Collect remaining personal details once using the verification files; do not ask for public course descriptions again.
